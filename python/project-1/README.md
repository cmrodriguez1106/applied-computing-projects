
# Python Basic Calculator

A basic graphical calculator developed using Python and Tkinter as part of my undergraduate Applied Computing coursework.

## Overview

This project implements a simple calculator with a graphical user interface (GUI), allowing users to perform basic arithmetic operations through an interactive application.

## Technologies

- Python
- Tkinter

## Features

- Graphical user interface built with Tkinter
- Basic arithmetic operations
- Interactive button-based input
- Real-time calculation functionality

## How to Run

1. Ensure Python is installed on your system.
2. Clone or download this repository.
3. Navigate to the project directory.
4. Run the application:

   ```bash
   python calculator.py
   ```
