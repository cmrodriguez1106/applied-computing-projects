
# Project 2: Python Wrestling Game

A wrestling-themed game developed using Python and inspired by the classic Rock, Paper, Scissors game mechanics.

## Overview

This project implements a wrestling-themed game where players compete using a Rock, Paper, Scissors-style system. Player selections determine the outcome of each matchup based on predefined rules.

## Technologies

- Python

## Features

- Wrestling-inspired gameplay
- Rock, Paper, Scissors-style combat mechanics
- Player versus computer gameplay
- Rule-based match outcomes
- Interactive gameplay and decision-making

## How to Run

1. Ensure Python is installed on your system.
2. Clone or download this repository.
3. Navigate to the project directory.
4. Run the game:

   ```bash
   python wrestling_game.py
   ```
